# App de Localização GPS

Aplicativo Android desenvolvido em Java para a atividade da faculdade.

## O que o aplicativo faz

- Busca a localização do celular ao abrir
- Mostra latitude, longitude e precisão em tempo real
- Abre no Google Maps a rota até o destino digitado

## Tecnologias

- Java
- Layout XML
- Android Studio
- Google Play Services Location
- Google Maps URLs

## Como executar

1. Abra o projeto no Android Studio.
2. Aguarde a sincronização do Gradle.
3. Conecte um celular Android com a Depuração USB ativada.
4. Clique em **Run**.
5. Permita o acesso à localização.
6. Digite um destino e toque em **Ver rota**.
